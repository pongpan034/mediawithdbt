**หัวข้อ:** ขนาดภาพ (Shot Sizes) และ มุมกล้อง (Camera Angles) ด้วยการเรียนรู้ผ่านภาพจริง (Visual Learning)

## 🌟 ฟีเจอร์เด่นของระบบ (Key Features)

### 1. 📱 ส่วนของผู้เรียน (Student Arena)
- **ไม่ต้องจำรหัสผ่าน:** นักศึกษาสามารถเลือกรหัสและชื่อ-นามสกุลจาก Dropdown รายชื่อ หรือกรอกชื่อใหม่ได้ทันที
- **Visual Learning ชัดเจน:** แสดงรูปภาพขนาดใหญ่ความละเอียดสูง พร้อมปุ่ม **"🔍 คลิกเพื่อขยายภาพ"** เต็มหน้าจอ
- **นาฬิกานับถอยหลัง Dynamic Timer:** หลอดเวลาเปลี่ยนสีตามความเร่งด่วน (เขียว ➔ เหลือง ➔ แดง) พร้อมเสียงเตือนเสมือนอยู่ในรายการเกมโชว์
- **ระบบคะแนน Speed & Combo Bonus:** ยิ่งตอบไวยิ่งได้คะแนนโบนัส พร้อมสะสมคอมโบเมื่อตอบถูกต่อเนื่อง
- **สรุปผลคะแนนละเอียด:** ตัดเกรด (S, A, B, C), สรุปเวลาที่ใช้ และแสดงเฉลยพร้อมข้อคิดหลักการจำสำหรับแต่ละขนาดภาพและมุมกล้อง
- **เอฟเฟกต์เสียงและพลุเฉลิมฉลอง:** ระบบ Web Audio API สังเคราะห์เสียงในตัว (เปิด/ปิดเสียงได้) พร้อมพลุ Confetti เมื่อได้คะแนนสูง

## 📐 เนื้อหาความรู้ที่บรรจุในระบบ (Knowledge Base)

| รหัส | ขนาดภาพ (Shot Sizes) | คำอธิบาย & การสื่อความหมาย |
| :--- | :--- | :--- |
| **ELS** | Extreme Long Shot (ภาพระยะไกลมาก) | แสดงทัศนียภาพกว้างใหญ่ ตัวแบบเล็กมาก บอกสถานที่/บรรยากาศ |
| **LS** | Long Shot (ภาพระยะไกล/เต็มตัว) | แสดงตัวบุคคลตั้งแต่หัวจรดเท้าพร้อมสภาพแวดล้อมรอบตัว |
| **MLS** | Medium Long Shot (Knee Shot) | ตัดกรอบตั้งแต่ระดับหัวเข่าขึ้นไปจนถึงศีรษะ |
| **MS** | Medium Shot (Waist Shot) | ตัดกรอบระดับเอวขึ้นไป นิยมในงานข่าวและบทสนทนา |
| **MCU** | Medium Close-Up (Chest Shot) | ตัดกรอบระดับหน้าอกขึ้นไป ดึงความสนใจมาที่สีหน้าท่าทาง |
| **CU** | Close-Up (ภาพระยะใกล้) | ตัดกรอบระดับไหล่ถึงศีรษะ เน้นสีหน้า แววตา และอารมณ์ |
| **BCU** | Big Close-Up (Choker) | ตัดกรอบตั้งแต่คางถึงหน้าผาก เน้นอารมณ์บีบคั้นรุนแรง |
| **ECU** | Extreme Close-Up (ภาพระยะใกล้มาก) | เจาะจงเฉพาะจุด เช่น ดวงตา ริมฝีปาก นิ้วมือ วัตถุขนาดเล็ก |

| มุมกล้อง (Camera Angles) | คำอธิบาย & การสื่อความหมาย |
| :--- | :--- |
| **Bird's Eye View / Aerial** | มุมมองนกมอง 90 องศาจากด้านบน ให้ภาพรวมผังเมืองหรือทิวทัศน์ |
| **High Angle (มุมสูง)** | กล้องอยู่สูงกว่าระดับสายตากดลงมา ทำให้ตัวละครดูเล็ก ด้อยค่า อ่อนแอ น่าสงสาร |
| **Eye Level (มุมระดับสายตา)** | กล้องขนานระดับสายตา ให้ความรู้สึกเป็นธรรมชาติ เสมอภาค เป็นกลาง |
| **Low Angle (มุมต่ำ)** | กล้องอยู่ต่ำแหงนขึ้น ทำให้ตัวละครดูยิ่งใหญ่ ทรงพลัง มีอำนาจ น่าเกรงขาม |
| **Worm's Eye View (มุมหนอนมอง)**| กล้องติดพื้นแหงนขึ้น 90 องศา ดูอลังการ โอ่อ่า และเหนือจริง |
| **Dutch Angle (มุมเอียง)** | แกนกล้องเอียงเฉียง สร้างความรู้สึกตึงเครียด ไม่มั่นคง สับสน ผิดปกติ |
| **Over the Shoulder (OTS)** | กล้องถ่ายข้ามหัวไหล่ตัวละครหนึ่งไปยังอีกคน นิยมในฉากสนทนา |
| **Point of View (POV)** | กล้องแทนสายตาตัวละคร ให้ผู้ชมรู้สึกเสมือนอยู่ในเหตุการณ์จริง |

## 🚀 วิธีการนำขึ้น Vercel (Step-by-Step Deployment)

1. เข้าสู่เว็บไซต์ **[vercel.com](https://vercel.com)** และเข้าสู่ระบบด้วยบัญชี GitHub ของคุณ
2. คลิกปุ่ม **"Add New..."** ➔ เลือก **"Project"**
3. เลือก Repository `pongpan034/mediawithdbt` แล้วกด **"Import"**
4. ในส่วน **Framework Preset** เลือกเป็น `Other` (หรือปล่อยว่างตามค่าเริ่มต้น)
5. กดปุ่ม **"Deploy"**
6. ภายใน 10 วินาที ระบบจะ Deploy เว็บแอปพลิเคชันเสร็จสมบูรณ์พร้อม URL ใช้งานจริงทันที!

## 💻 วิธีการเปิดใช้งานบนเครื่องคอมพิวเตอร์ (Local Run)

คุณสามารถเปิดใช้งานได้ง่าย ๆ โดย:
1. ดับเบิลคลิกเปิดไฟล์ `index.html` บนเบราว์เซอร์ (Chrome, Edge, Safari, Firefox) ได้ทันทีโดยไม่ต้องติดตั้งโปรแกรมเพิ่มเติม
2. หรือรันคำสั่ง Local Server ผ่าน Terminal:
   ```bash
   npx serve .
   ```
